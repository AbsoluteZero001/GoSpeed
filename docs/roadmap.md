# GoSpeed 路线图

路线图描述方向，不代表承诺。任何版本发布前都必须满足同一套真实性与测试要求：
不使用模拟数据、不输出未采集指标、`go test ./...` 全绿。

## v0.1.0 当前版本（已实现）

- 项目初始化与模块化架构
- CLI：`test` / `server` / `nodes` / `version`
- 本地 HTTP 测速服务器：`/health`、`/ping`、`/download`、`/upload`
- HTTP RTT 延迟测试（多采样、min/avg/max、jitter）
- 单连接下载测速（真实字节计数、不可压缩载荷）
- 单连接上传测速（服务端字节确认与一致性校验）
- 稳定性保护：context 取消、阶段超时、缓存与压缩规避、零时长保护
- 结构化 JSON 结果：原始字节数、原始耗时、测量窗口、配置快照
- 单元测试（含 `httptest` 本地环境）与 `-race` 验证
- 文档与 GitHub Actions CI（Windows / Linux / macOS）

## v0.2.0 测量能力增强

- 多连接并发测速（2 / 4 / 8 / 16，由配置控制）
- 实时速率采样序列（为曲线与波动分析提供原始数据）
- 测速时长精确配置与预热阶段正式化
- 结果稳定性分析：中位数、四分位、离散程度
- 连接数对结果的影响研究（同样条件下对比）

## v0.3.0 多节点与公网测试

- 多节点管理：自动选择、按 RTT 排序、故障切换
- 公网测速节点支持（HTTPS、并发限制、认证）
- 多次测速对比与差异解释
- 本地测速历史记录（SQLite 或 JSON Lines）

## v0.4.0 本地 Web UI

- 本地 Web 界面（仪表盘式布局，高信息密度、低装饰）
- 实时速率曲线、阶段进度
- 节点选择界面与结果详情
- 历史结果浏览

## v0.5.0 桌面客户端

- Wails + Vue 3 + TypeScript 桌面应用
- Windows 桌面安装包
- 深色 / 浅色主题
- 历史结果可视化与导出（JSON / CSV）

## v0.6.0 跨平台与诊断

- Linux / macOS 桌面支持
- 网络接口状态显示（协商速率与吞吐量严格区分，未知时显示 `N/A`）
- 更完整的网络诊断能力

## 未来版本

- ICMP / UDP 网络质量测试（真实丢包率）
- 负载延迟（loaded latency）与 Bufferbloat 分析
- 多节点测速网络与结果聚合
- 持续网络监控与告警

## 明确不做的事

- 不伪造任何测速数字；
- 不把网卡协商速率当作实测吞吐；
- 不把 HTTP 请求失败率当作丢包率；
- 不在没有真实数据时显示 `0`、`0%` 或"正常"状态。
