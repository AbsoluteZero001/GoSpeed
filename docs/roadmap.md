# GoSpeed 路线图

路线图描述方向，不代表承诺。任何版本发布前都必须满足同一套真实性与测试要求：
不使用模拟数据、不输出未采集指标、`go test ./...` 与 `go test -race ./...` 全绿。

## v0.1.0（已实现）

- 项目初始化与模块化架构
- CLI：`test` / `server` / `nodes` / `version`
- 本地 HTTP 测速服务器：`/health`、`/ping`、`/download`、`/upload`
- HTTP RTT 延迟测试（多采样、min/avg/max、jitter）
- 单连接下载 / 上传测速（真实字节计数、服务端确认）
- 稳定性保护：context 取消、阶段超时、零时长保护
- 结构化 JSON 结果与基础单元测试
- 文档与 GitHub Actions CI（Windows / Linux / macOS）

## v0.2.0 当前版本（已实现）

- 多连接并发下载 / 上传（1..16，端到端测试覆盖 1 / 4 / 8 / 16）
- 共享字节预算：`--max-bytes` 表示阶段总预算，不随连接数放大
- 统一测量窗口：1 连接与 N 连接的速率都基于共享窗口，绝不把连接时间或速率相加
- 连接级证据：`connection_reports` 记录每条连接的状态、字节数、
  上传时还有服务端确认字节数与错误信息
- 部分连接失败时输出结果 + 告警（含有效连接数），全部连接失败直接报错
- 实时速率采样：默认 200 ms 可配置，使用真实单调时钟窗口计算瞬时速率
- 描述性统计：平均、中位、最小、最大、样本标准差（n-1）、变异系数；
  采样不足时输出 `N/A`（JSON `null`）
- CLI：TTY 动态进度条 + 普通文本降级输出；JSON 模式 stdout 始终是纯 JSON
- 并发与字节一致性测试，`go test -race ./...` 通过

## v0.3.0 稳定性分析与多节点

- 四分位（P25 / P75 / IQR）与更完整的波动分析
- 同一节点多次测速的聚合统计（多次运行中位数，而不是单次窗口平均）
- 连接数对结果的影响对比视图（1 / 4 / 8 / 16 同条件对比）
- 多节点管理：自动选择、按 RTT 排序、故障切换
- 公网测速节点支持（HTTPS、并发限制、认证）
- 本地测速历史记录（SQLite 或 JSON Lines）

## v0.4.0 本地 Web UI

- 本地 Web 界面（仪表盘式布局，高信息密度、低装饰）
- 实时速率曲线（消费现有 `samples` 与 `Progress` 事件）
- 阶段进度、剩余时间与节点选择
- 历史结果浏览与 JSON / CSV 导出

## v0.5.0 桌面客户端

- Wails + Vue 3 + TypeScript 桌面应用
- Windows 桌面安装包
- 深色 / 浅色主题
- 历史结果可视化

## v0.6.0 跨平台与诊断

- Linux / macOS 桌面支持
- 网络接口状态显示（协商速率与吞吐量严格区分，未知时显示 `N/A`）
- 更完整的网络诊断能力

## 未来版本

- ICMP / UDP 网络质量测试（真实丢包率）
- 负载延迟（loaded latency）与 Bufferbloat 分析
- 多节点测速网络与结果聚合
- 持续网络监控与告警

## 明确不做的事

- 不伪造任何测速数字；
- 不对 Mbps 乘任何“接近商业工具”的补偿系数；
- 不把网卡协商速率当作实测吞吐；
- 不把 HTTP 请求失败率当作丢包率；
- 不在没有真实数据时显示 `0`、`0%` 或“正常”状态。
